공직자통합메일도우미(학교) 개인정보처리방침

시행일: 2026년 11월 26일

이 확장프로그램은 학교 행정실 직원을 위해 만든 도구로, 공직자통합메일(korea.kr)의 새 메일을 알려 주고, 메일 목록을 사용자 PC 안에서 빠르게 찾게 해 주는 비공식 도구입니다. 행정안전부 또는 공직자통합메일 운영 기관과 관계가 없습니다.

1. 처리하는 정보

사용자가 로그인한 공직자통합메일에서 다음 정보를 읽습니다.

  • 메일함 이름과 메일함별 메일 수, 안 읽은 메일 수
  • 받은·보낸·내게 쓴·사용자가 만든 메일함에 있는 메일의 제목, 보낸 사람(보낸 메일은 받는 사람), 이메일 주소, 날짜, 읽음 여부, 첨부 여부, 메일 번호

메일 본문, 첨부파일 내용, 주소록, 인증서, 비밀번호에는 접근하지 않습니다.

2. 이용 목적

  • 새 메일이 왔을 때 화면 오른쪽 아래 알림 창과 윈도우 알림으로 보여 주고, 안 읽은 메일 수를 아이콘에 표시합니다.
  • 메일 목록을 사용자 PC에 모아 두고, 공직자통합메일 화면 안의 ‘빠른 검색’ 탭(또는 따로 연 검색 화면)에서 제목·보낸 사람으로 빠르게 찾고 업무 단계·거래처별로 나눠 보여 줍니다.
  • 사용자가 정한 낱말이나 보낸 사람의 새 메일을 눈에 띄게 표시합니다.
  • (사용자가 끄지 않은 경우) 로그인이 풀리지 않도록 공직자통합메일의 ‘이용 연장’과 같은 요청을 주기적으로 보냅니다.

3. 저장과 전송

  • 위 정보와 사용자 설정은 사용자 PC의 크롬 저장소(chrome.storage, IndexedDB)에만 저장됩니다.
  • 개발자 서버가 없으며, 어떤 정보도 개발자나 제3자에게 전송하지 않습니다.
  • 통신은 사용자의 브라우저와 공직자통합메일 서버(kmmbox.korea.kr, mail.korea.kr) 사이에서만 일어납니다.
  • 메일을 옮기거나 지우거나 읽음으로 바꾸는 요청은 보내지 않습니다. 사용자가 검색 결과를 눌러 메일을 열면, 공직자통합메일 화면에서 메일을 직접 연 것과 같이 그 메일이 읽음으로 바뀝니다.
  • 사용자가 ‘메일본문’·‘첨부이름’ 검색을 고르면, 공직자통합메일 화면의 검색칸에 낱말을 넣고 검색을 대신 눌러 줍니다. 이 검색은 공직자통합메일 서버가 처리합니다.
  • 분석 도구, 광고, 추적 코드를 쓰지 않습니다.

4. 보관과 삭제

  • 검색 화면의 ‘저장된 목록 지우기’로 모아 둔 메일 목록을 언제든 지울 수 있습니다. 메일 서버의 메일은 지워지지 않습니다.
  • 확장프로그램을 삭제하면 저장된 정보도 모두 함께 삭제됩니다.
